# DocrAI explainer site

The landing page for `docrai.io` while the domain still points at a static
host. **`index.html` is generated, do not edit it by hand:**

```bash
node explainer/bygg.mjs
```

The script builds `index.html` from `apps/api/src/om-page.html` and the shared
header/footer in `apps/api/src/partials/`, and copies `site.css` and the
self-hosted font. Sub-pages, the demo and the pilot form live on the Express
host, so the script points those links there. No Google Fonts and no other
third-party requests — the privacy page promises that. Run the script after
every change to the landing page, header, footer or stylesheet.

Domain split (per the live setup): this site is meant for `docrai.io`; the
product itself lives at `app.docrai.io` (that's what the "Åpne DocrAI" button
links to).

**Decision 2026-09-28:** `docrai.io` is to be pointed at the Express sales pages
(`apps/api/src/om-page.html` and friends) instead of this site — see
`docs/DEPLOYMENT.md` → «Domener» and `docs/nettside-masterplan.md` §0. This
folder stays in the repo until the switch is verified, then it can be removed.

## Deploying to Render (Static Site)

1. New → Static Site, point at this repo.
2. Root directory: `explainer`
3. Build command: (leave empty)
4. Publish directory: `explainer` (or `.` if root directory is already set to `explainer`)
5. Custom domain: `docrai.io`

No environment variables needed.

## Files

- `index.html` — generated by `bygg.mjs`
- `bygg.mjs` — the build script
- `site.css`, `fonts/manrope-latin.woff2` — copied from `apps/api/src/assets/` by the script
- `favicon.png`, `apple-touch-icon.png`, `og-bilde.png` — copied from
  `apps/api/src/assets/` (same brand assets used on the existing sales pages)
